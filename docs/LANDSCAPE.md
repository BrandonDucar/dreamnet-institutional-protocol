# Agentic Infrastructure Landscape

Snapshot date: 2026-07-28.

DreamNet is not the only project exploring persistent agents, agent economies,
interoperability, identity, reputation, or simulated societies. Its proposed
center is the composition of these concerns into operational institutions.

## Adjacent Systems

| Area | Examples | What they establish |
| --- | --- | --- |
| Durable execution | Temporal, LangGraph | Agent workflows can persist, pause, resume, and recover. |
| Interoperability | MCP, A2A, NANDA, Agent Network Protocol | Agents can discover systems, exchange tasks, and use tools across boundaries. |
| Identity and trust | ERC-8004, EAS, Agentverse | Agent identity, validation, attestations, and reputation can be represented in shared registries. |
| Agent economies | Olas, Fetch.ai | Autonomous services can be composed and economically coordinated. |
| Societies and civilizations | Project Sid, AgentSociety, Generative Agents | Large populations of simulated agents can exhibit social behavior and emergent organization. |
| Provenance and credentials | W3C PROV-O, W3C VC | Evidence lineage and portable credentials have mature standard models. |
| Long-term memory | Hindsight and related memory systems | Agent memory can be structured beyond a chat transcript. |

## DreamNet's Proposed Center

The public systems above generally specialize. DreamNet is testing one
continuous institutional path:

```text
durable work
  -> bounded capabilities
  -> institutional memory
  -> competency and education
  -> genealogy and succession
  -> receipts and provenance
  -> claims and counterclaims
  -> independent verification
  -> portable federation
  -> scoped reputation
  -> human governance and homeostasis
```

We did not identify a public project in this review that visibly combines every
stage as one executable institutional contract. That is an inference from the
public materials reviewed, not a claim that no private or unpublished system
does so.

## The Meaning of "Emerging Civilization"

DreamNet uses the phrase as an engineering hypothesis, not a claim of
sentience. A civilization-ready agent system should be able to:

- preserve institutional knowledge across process and model death;
- educate and assess new participants;
- constrain authority by earned competency;
- dispute and revise knowledge;
- federate without sharing all private state;
- preserve lineage and responsibility;
- coordinate scarce resources;
- survive disagreement, failure, and leadership succession;
- remain subject to human and policy authority.

Project Sid and AgentSociety demonstrate that "AI civilization" is already a
serious simulation and research topic. DreamNet's distinct experiment is
whether institutional machinery can be made operational, portable, and
auditable outside a closed simulation.
